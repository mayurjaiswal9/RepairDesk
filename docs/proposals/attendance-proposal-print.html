Proposal only · switches stay off

Attendance monitoring

Pictures of the proposed RepairDesk screens. This is not a build. Attendance, Check-in, On-duty tracking, Travel allowance, Customer ETA, and Allow start outside the office geofence stay off. The shop stays the one already saved.

  • Technician home. A duty card appears only while Attendance is on. Start day waits up to 8 seconds for a fix. The server decides inside or outside the saved shop pin and radius (150 m by default). Not now leaves the day unstarted. Jobs and Appointments stay available.
  • Outside the shop. A trustworthy fix beyond 150 m is refused when allow-start-outside is off. The day does not start. The same outside fix starts the day when that switch is on, flagged Outside shop.
  • Weak or mocked fixes still start the day. Staff see Location missing, Location uncertain, or Mocked location. Opening a job, starting a repair, and Start Navigating are unchanged.
  • Staff and Admin list. A new Attendance item under Work, on the web and the phone. Today in India, one row per active technician, including people who have not started. No coordinates. The web page can download the same columns.
  • Office location. The existing administrator screen. This slice does not add a switch and does not turn any on.

Sample day 18-10-2026. Names and times are sample rows so the columns are readable. The 420 m distance is a sample. No customer phone numbers are shown.

End day is on the home once the day is open. It is always allowed. A missing or outside fix is recorded with the end. After End day the card reads Ended, with the time and Manual.
