2. Sign in

  1. Open the portal URL.
  2. Enter your username and password.
  3. Click Sign in.

2.1 First sign-in — choose a new password

If the account still uses the password it was set up with, you must change it before the dashboard opens.

  1. Enter the current (temporary) password from your administrator.
  2. Enter a new password (minimum 8 characters) and confirm it.
  3. Click Update password.

3. What Staff can do

Staff work the counter and the phone. The sidebar is Dashboard, Repair Requests, Locations, Jobs, Appointments, and Customers. You cannot open Staff management, Device Categories, Business Settings, or Office location. Repair Requests opens a page that says review is limited to administrators — create the request from the dashboard instead.

You canWhere
Create a request, including the visit pinDashboard → Create request
Look up customers and their historyPeople → Customers
See technician positions and travel timeWork → Locations
Assign a technician, move the pin, schedule, add notes and photosWork → Jobs → open the job
See the week’s appointments and unscheduled jobsWork → Appointments

After you create a request it is Pending review. An administrator approves it; that creates the job. You then assign the technician on the job — not on the Create request screen.

4. Dashboard

After sign-in you see your name and the Staff sidebar. Pending review is a count only. Active jobs and Unscheduled jobs open the job list. Create request is the intake shortcut. Locations is the technician map.

5. Create a request

Use this when a customer walks in or calls and did not submit from the mobile app. The request is owned by them, not by you.

  1. Dashboard → Create request (or Customers → open someone → New request).
  2. Find or create the customer.
  3. Check Contact for this request. You can edit name / mobile without changing their account.
  4. Fill Request details: device type, optional brand/model, issue (at least 10 characters), how they contacted you, optional photos.
  5. Click Create request →. Save for review parks the same pending request.

5.1 New walk-in customer

  1. Click + New customer.
  2. Enter Name and Mobile. Username and password are optional.
  3. Click Create customer.

If a password was generated, a dialog shows it once. Give it to the customer for the mobile app. It cannot be retrieved again.

5.2 Finish the request

You land on the customer page. The new request is Pending review. There is no job yet.

6. Assign a technician

Assignment is on the job. Open Work → Jobs after the request is approved. The job uses the same reference number as the request.

  1. Open the job.
  2. In the Technician card, click Assign.
  3. Choose an active technician and click Assign.

Service address, the job pin, and the technician map

On a new request

The technician follows the pin. Type the address, then search a place (at least 5 letters; the list refreshes every 5 seconds), paste the Maps link the customer sent and click Use this pin, or click Find on map and drag the pin. A photo of a map is not a pin. A typed area name without a picked building is only the centre of that area.

On a job

The search box stays hidden until you click Edit. Then search, paste the customer’s link, or drag the pin, and click Save. Cancel leaves the stored address unchanged. Start Navigating opens Google Maps directions to that pin.

Locations

Work → Locations. O is the shop, T is a technician who opened an assigned job with location allowed, and unmarked pins are jobs. Click Refresh. Minutes say from the technician or from the office. A line that says estimated is a straight-line fallback. Start day is the work-day record on Attendance. It does not move the T pin.

If the suggestion list does not appear, paste the customer’s Maps link or drag the pin. The message Place search is unavailable means Google place search is switched off; the map and the customer link still work.

Attendance

Work → Attendance. The same list is on the phone under Attendance when you are signed in as Staff. Technicians do not see it. The page opens on today in India. One row per active technician, including people who have not started. Coordinates are not shown.

ColumnWhat it shows
StatusNot started, On duty since a time, Ended, or Auto-ended
Start flagInside shop, Outside shop, Location uncertain, Location missing, or Mocked location
EndManual when they tapped End day. Auto when the shop’s end-of-day time closed it
HoursTime between start and end, for example 7h 40m

Set From and To, then Show. The range can cover at most 31 days. A longer range says Date range must be 31 days or less.

While Attendance is off, the list still opens. The notice says an administrator turns it on from Office location. Days already recorded stay in the list. You cannot change the switch.

After an administrator turns Attendance on and saves, the technician’s home screen shows Work day. Start day stores the time and whether they were at the shop. A fix is clear when its accuracy is no wider than the shop radius. A clear fix outside the shop circle is refused unless the office allows a start outside the shop. End day always closes an open day. At 19:00, unless the office changed that time, an open day closes by itself and the technician gets one in-app notice. Opening a job, Start Repair, and Start Navigating do not check the work day.
